# Figure Peek 图窗

Figure Peek 是面向 Zotero 9 PDF 阅读器的小插件。单击正文中的图号、表号、公式号或其他常见编号对象时，它会定位同一篇 PDF 中的对应内容，并把内容固定显示在一个无系统边框的小窗中；阅读位置不会被自动改变。

## 支持的引用编号

- 中文：`图3.4`、`图 3.4`、`图３．４（a）`、`图3-4`、`图3.4（a-c）`
- 英文：`Figure3.4`、`Figure 3.4`、`Fig. 3.4`、`Fig. S3b`、`Figure A-2`
- 跨行图号：`图` 后换行 `3.8`，或 `Figure` 后换行 `3.8`
- 中文表格：`表3.4`、`表格 3.4`、`表３－４（a）`
- 英文表格：`Table3.4`、`Table 3.4`、`Tab. S3`、`Table A-2`
- 中文公式：`公式（3.8）`、`式(3.8)`、`方程 3.8`
- 英文公式：`Equation (3.8)`、`Eq. 3.8`、`Eqns. (3.8)`、`Formula (3.8)`
- 其他常见编号对象：`Scheme 2.1`、`Algorithm 4`、`Listing 5.1`、`Chart 3.2`、`Box 1`，以及中文的 `算法2.1`、`流程图3.2`、`清单5.1`、`附图A.1`

## 使用

1. 在 Zotero 中打开带有可检索文本层的 PDF。
2. 使用“指针”工具，单击正文中的完整图号。
3. 图窗会固定显示对应图片、表格或公式。表格会优先按表题定位，并截取表题下方的表格区域；窗口会根据内容比例自动收紧，尽量让预览占满可视区域；仍可拖动右下角的斜线手柄自由调整大小。
4. 标题栏的 `−`、百分比和 `＋` 可缩放内容；光标置于预览内容上时，滚轮向上放大、向下缩小，并以光标所在位置为中心缩放。光标置于右侧滚动条时，滚轮上下移动预览；置于底部滚动条时，滚轮左右移动预览。双击内容可在“适配”和 200% 之间切换；“放大/还原”可让图窗铺满阅读区域。
5. “整页”可在裁剪内容与原 PDF 页之间切换；“原图”会主动跳到原始位置；`Esc` 或 `×` 关闭。图窗不再显示页码和图注文字，以保持紧凑。手动调整的图窗尺寸会在本次 Zotero 会话中保留。
6. 拖动标题栏的空白位置可移动图窗；预览放大后，按住图片左键并拖动即可平移查看细节。

插件优先复用 PDF 已有的内部链接；没有内部链接时，会先检索引用页附近，再检索全文。所有识别与渲染均在本机 Zotero 内完成，不上传 PDF 或图片。

## 安装

1. 从 GitHub 的 **Releases** 下载对应版本的 `figure-peek-<version>.xpi`。
2. 在 Zotero 中打开“工具 → 插件”，点击齿轮图标，选择“从文件安装插件…”。
3. 选择下载的 XPI 文件；安装后确认 Figure Peek 图窗处于“已启用”状态。

每个版本的 XPI 由以下命令构建：

```powershell
npm run build
```

`dist/` 不提交到源码仓库；发布新版本时，应把其中生成的 XPI 作为 GitHub Release 的附件上传。

## 已知边界

- 扫描件必须先有 OCR 文本层，插件才能读取图号和图注。
- PDF 没有统一的“图/表对象”；矢量图、多栏、跨页图、跨页表或图表题位于非常规位置时，自动裁剪可能不完整。公式预览也依赖公式编号处于可检索的文本层中。此时使用“整页”查看。
- Zotero 翻译侧边栏没有稳定的公开扩展接口。本插件仍使用阅读器内的固定预览窗，不会修改 Zotero 的原生侧边栏布局。
- 插件依赖 Zotero 9.0 的 Reader 私有适配层，因此清单把兼容版本限定为 `9.0.*`。升级到新的 Zotero 次版本前应重新验证。

## 开发

```powershell
npm test
npm run build
```

构建结果位于 `dist/figure-peek-<version>.xpi`。XPI 根目录直接包含 `manifest.json`、`bootstrap.js`、`core.js`、`figure-peek.js` 和 `renderer-bridge.js`。
